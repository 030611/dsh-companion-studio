# Contributing

Small, testable changes are welcome.

1. Use Node.js 22.19 or newer and the pnpm version declared in `package.json`.
2. Run `pnpm install`, then `pnpm check`.
3. Keep character artwork in a separate pack. Every pack must declare its author, license and source provenance.
4. Do not include prompts, reasoning, tool arguments, tool results, credentials or private session data in fixtures, screenshots or issues.
5. Describe the observed behavior, the expected behavior and the verification performed.

By contributing code, you agree that your contribution is licensed under the repository's MIT license.
