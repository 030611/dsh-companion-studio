# DSH Companion Studio

[English](README.md) | 简体中文

一个面向 DeepSeek Harness 的早期桌宠引擎，强调隐私边界与可扩展角色包。它并不是又一个余额或费用监控器，而是把 DSH 提供的会话事实转化为有用的环境反馈，同时把角色美术拆分为可独立安装的资源包。

> 当前状态：公开核心预览版。运行时、隐私边界、状态机、角色包规范与打包清单均可测试。仓库不内置角色美术；在真实 profile 验收完成前，npm 发布仍保持关闭。

## 与普通桌宠的区别

- 八种明确状态：待命、思考、流式回复、工具调用、等待用户、成功、错误和睡眠。
- 紧凑的实时气泡只显示**助手回复文字**，不会选择推理、提示词、工具参数或工具结果。
- 展示前会遮盖疑似凭据的字符串，回复预览也可以单独关闭。
- 可通过浏览器本地 Web Speech API 朗读完成回复；默认关闭，不会把音频或文字发送给语音服务，并可从桌宠菜单立即停止。
- 可选的每小时变化会轮换当前角色的服装并播放短展示动作；默认关闭。
- 语音菜单会自动排序本机已安装的中文语音，也允许显式选择并试听。
- 支持显示、收起和完全隐藏；完全隐藏后可通过会话页顶部按钮恢复。
- 角色与服装由数据驱动，外部角色插件可以在核心加载前后注册。
- 用户可上传一张本地 PNG/WebP 作为私人桌宠；图片仅在本地标准化并保存到 IndexedDB，刷新后仍可恢复。
- 尊重系统的 `prefers-reduced-motion` 减少动画设置。

## 内置演示元数据

公开核心只包含一个不带美术的元数据占位角色 **星汐 / 星潮鲸灵**，用于测试角色选择器和服装设置。用户上传本地图片或安装单独授权的角色包之前，它会以图形占位符显示。本仓库不会分发鲸鱼女仆或第三方角色图片。

## 角色包模型

核心包保持精简。独立安装的 DSH 客户端插件可以从 `dsh-companion-studio/client-api` 导入 `registerCompanionPack`，注册一份角色清单。每份清单会绑定许可证、配色、服装和可选动画精灵图。基于全局 Symbol 的注册表兼容两种加载顺序，并为热重载返回清理函数。

v1 契约与动画要求见 [docs/PACK-SPEC.md](docs/PACK-SPEC.md)。

## 用户自定义桌宠

设置面板接受一张不超过 5 MB、分辨率不超过 2048×2048 / 419 万像素的 PNG 或 WebP。DSH 会在本地解码并重新编码为静态 PNG，保留透明通道，同时移除元数据和动画载荷。系统不接受 SVG、HTML、远程 URL 或任意脚本。处理后的 Blob 只保存在浏览器 IndexedDB；对象 URL 仅在插件挂载期间存在，并会在删除或卸载时释放。

单张图片会复用核心提供的八种轻量 CSS 动作，因此用户无需制作精灵图。高级的逐状态美术仍通过显式角色包提供。本插件不声称可以自动抠图；上传透明背景素材可获得最佳效果。

## 隐私边界

回复气泡读取官方 `ConversationSnapshot.partial` 与已完成的助手节点，并且只接受类型为 `text` 的内容。以下内容不会进入预览或朗读：

- 用户提示词或注入上下文；
- 推理块；
- 工具名称、参数或结果；
- 审批和提问载荷；
- 遥测、余额或模型价格。

回复预览会限制长度，并在本地朗读前再次清理。朗读功能需要用户主动开启。

## 本地开发

```bash
# Node.js 22.19 或更新版本
pnpm install
pnpm check
pnpm pack --dry-run
```

构建完成后，可以按以下方式在本地评估：

```bash
dsh plugin --profile web add link:/absolute/path/to/dsh-companion-studio
```

仓库内的 `cordis.patch.yml` 使用 DSH 的 profile bundle patch 机制。当前是源码预览版，并非已经发布的 npm 包。

## 公共仓库边界

- MIT 许可证覆盖本仓库源代码。
- 仓库与软件包不包含角色美术。
- 用户上传的桌宠只保存在该用户的浏览器中。
- 外部角色包作者需要声明兼容许可证并保存素材来源记录。

详情见 [docs/ASSET-PROVENANCE.md](docs/ASSET-PROVENANCE.md) 与 [SECURITY.md](SECURITY.md)。
