# Asset policy and provenance gate

This public core intentionally bundles no character artwork.

The MIT license covers the repository's source code. It does not grant rights to artwork supplied by users or installed through external companion packs. Public availability on social media is not treated as a redistribution license.

## External pack requirements

Before a character pack is linked from this project, it should record:

1. the creator and exact source or generation record for every asset;
2. permission for any visual references used;
3. an explicit redistribution license;
4. hashes for the reviewed release files; and
5. an in-app screenshot confirming the reviewed assets are the shipped assets.

User-uploaded private pets are outside the distribution boundary: they remain in the user's browser and are not included in this repository or its package.
